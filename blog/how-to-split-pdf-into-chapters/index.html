How to Split a PDF into Chapters or Sections

August 11, 2026 5 min read By PDF99 Team

Large PDF documents — textbooks, annual reports, long research papers, compiled manuals — are cumbersome to work with as single files. Splitting them into chapters or sections makes them faster to load, easier to navigate, simpler to share selectively, and more manageable to annotate. Here's how to do it efficiently using free tools.

Before you split: know what you're working with

The split approach depends on what the document contains. Digitally created PDFs (exported from Word, InDesign, Google Docs) typically have bookmarks and a table of contents that tell you exactly which pages correspond to which chapter. Scanned PDFs are image-based and usually lack bookmarks — you'll need to know the page numbers manually or browse through to find chapter boundaries.

Open the PDF in any viewer and check the left sidebar. If there's a bookmarks or outline panel with chapter titles that jump to specific pages, you can use those page numbers directly when splitting. If there's no outline, scroll through to note the page number where each chapter starts (visible in the viewer's page counter).

Splitting by page range using PDF99

The PDF99 Split PDF tool is the cleanest approach for most chapter-splitting tasks.

  1. Upload your PDF — every page renders as a visual thumbnail so you can see the content of each page
  2. Use the page range input to specify the pages you want to extract. For a chapter that runs from page 23 to 67, type 23-67 in the range box and press Apply — the tool highlights exactly those pages
  3. Choose your output format: "Individual PDFs in a ZIP" gives you one PDF per selection, "Selected pages as one PDF" merges your selection into a single document
  4. Click Extract Pages and download

For splitting a full book into all its chapters, the most efficient approach is to run multiple extractions. Extract Chapter 1 pages (1-22), download, then extract Chapter 2 pages (23-67), download, and so on. Alternatively, if you want all chapters at once, extract each range separately and download the individual ZIPs.

Splitting by every page (creating a PDF per page)

If you want every page as a separate PDF — useful for archiving individual forms from a batch scan, or separating every page of a multi-page scan for individual upload — the default behaviour of the PDF99 split tool delivers this. Upload your PDF, leave all pages selected (the default), choose "Individual PDFs in a ZIP", and click Extract. Each page becomes its own numbered PDF in a downloaded ZIP file.

Extracting a single page

For quick single-page extraction — pulling a specific diagram, a signature page, or a single figure from a large document — click just that page's thumbnail in the split tool, deselecting all others, then extract. One PDF file for one page, downloaded instantly.

Dealing with large PDFs (200+ pages)

Very large PDFs take longer to process because every page has to be rendered as a thumbnail. For a 500-page PDF, initial loading can take 30-60 seconds on a typical browser. Be patient — once all thumbnails have rendered, the selection and extraction process is fast.

If your PDF is very large and the browser is struggling, consider splitting the task. Extract the first half of the document (pages 1-250) as a separate PDF, then extract the second half (pages 251-500). Now work with two more manageable files rather than one enormous one. The merge tool can always combine them again if needed later.

Naming your split chapters sensibly

The output files from PDF99's split tool are named using the original filename plus "extracted" or page numbers. Rename them immediately after downloading to reflect their actual content — "Chapter-01-Introduction.pdf", "Chapter-02-Literature-Review.pdf" and so on. Consistent naming makes the split files far more useful in the long run, especially if you're building a reference library.

After splitting: compress if needed

Individual chapter PDFs are smaller than the original by definition, but individual chapters from image-heavy documents can still be several MB each. If you need to share chapters by email or upload them to a portal with size limits, run the extracted chapters through the PDF99 Compress tool before sending.

Splitting a book into chapters: practical step-by-step

A textbook or long reference document is the most common use case. Here's an efficient approach for splitting a complete book into individual chapters.

First, find the page numbers. Open the PDF in any viewer and check whether it has bookmarks (the outline/navigation panel on the left). If bookmarks exist, they tell you exactly which page each chapter starts on. If no bookmarks exist, manually note the starting page of each chapter by scrolling through — most textbooks have a table of contents that lists page numbers.

Then use PDF99's split tool to extract each chapter one at a time. Type the page range for Chapter 1 (e.g. 1-22), click Extract, download the file, rename it immediately (e.g. Chapter-01-Introduction.pdf), then go back and extract Chapter 2 (23-67). Working methodically through the book this way takes 5-10 minutes for a typical textbook and produces a clean set of individual chapter files.

Rename files immediately after downloading — don't let your Downloads folder fill up with files named 'split-pdf-output.pdf' that you'll have to identify later.

Splitting annual reports and business documents

Annual reports, board packs, and large business documents are frequently split for distribution. Different stakeholders need different sections — the finance team needs the financial statements, the marketing team needs the brand performance section, the board needs the executive summary.

For these documents, the approach depends on whether recipients need to know what they're missing. If you're sending just the financial statements, extract those pages and send them as a clean file labelled 'Financial Statements — Annual Report 2026'. Don't send the whole report with a note saying 'see pages 45-67' — extracting the relevant pages is more professional and easier for the recipient.

Splitting by even and odd pages for double-sided scans

A specific technical use case: some scanners produce two-sided document scans where odd pages come from one scan pass and even pages from another, resulting in separate PDFs that need to be interleaved. This is different from simple chapter splitting.

For this interleaving problem, PDF99's merge tool won't interleave — it appends. You'd need a dedicated interleaving tool or a script. However, for the simpler case of extracting just the odd or even pages from a double-sided scan where pages were scanned out of order, the split tool's range input handles it: type 1,3,5,7,9 or similar to extract specific pages.

When splitting isn't the right answer

Not every large PDF benefits from splitting. Consider whether recipients actually need individual files, or whether a well-bookmarked single PDF is more useful. A 200-page PDF with a clickable table of contents and working bookmarks is often easier to navigate than 20 separate chapter files that users have to open individually.

Adding bookmarks to an existing PDF requires a desktop tool like Adobe Acrobat or the free PDF editor Sejda. If the PDF was created from a Word document that had heading styles applied, the bookmarks often export automatically — check the source document's export settings before splitting unnecessarily.

The split-vs-bookmark decision: split if different people need different sections, or if file size is a constraint. Keep whole if recipients need the full document and navigation tools (bookmarks, search) will serve them better than separate files.

Compressing after splitting

Individual chapter PDFs are often still larger than necessary, especially if they come from a scan-heavy book. After splitting, run each chapter through PDF99's compress tool at 70-80% quality. A 50-page scanned chapter that starts at 25MB might compress to 4-6MB — much more manageable to share by email or upload to a course platform. If you need to hit specific size limits for an LMS or email system, the target-size compression tools handle it automatically.
